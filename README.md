# AutoKeep

Android vehicle maintenance tracker. A car-health dashboard, not accounting software.

Add a car, get a seeded service checklist, then see what’s done, what’s due next, and what it costs. Record a service and AutoKeep sets the next due by mileage or months, whichever comes first.

## Features

- Garage and vehicle details (make, model, engine, mileage, photo)
- Maintenance checklist with due-soon / overdue health
- Service recording with automatic next-due
- Reminders, service history, and expenses (fuel, repairs, parts, other)
- Light / dark theme and color schemes

One car is free.

## Stack

Kotlin, Jetpack Compose, Material 3, Room, Navigation Compose. minSdk 24.

## Run

Open the project in Android Studio and run the `app` module on a device or emulator.
